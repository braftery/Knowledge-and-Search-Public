# MetricTile

One quality number with its denominator.

- Label in `tools-label`, value in `tools-metric` with tabular figures, denominator or context in `tools-meta`.
- Always show the base ("18 of 20"), never a bare percentage. Mark the figure illustrative.
- Tiles in a row share one height. Four at most.
- A tile that links somewhere has a tertiary link under it; the tile itself is not a button.
- Consumer provides: label, value, context line, and an optional link.
