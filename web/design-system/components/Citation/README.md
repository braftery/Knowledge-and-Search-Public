# Citation

Where an answer came from. Every answer on every surface has one.

- Internal tools: title, version, who approved it and when, and a link to the source. `ink-muted` with the file-text icon; the link is underlined `action`.
- Member surfaces: a plain-language source and date only. Never a unit ID, version number or knowledge base name.
- Sits directly under the answer text, before any actions.
- Consumer provides: title, version, approver, date, source link, and the audience.
