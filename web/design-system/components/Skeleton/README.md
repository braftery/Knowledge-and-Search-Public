# Skeleton

Placeholder while content loads. Mirrors the final layout exactly so nothing shifts.

- `surface-sunken` blocks with `radius-sm`. A gentle pulse, which stops under reduced motion.
- Appear after 200ms, stay at least 400ms. Saved answers load instantly and never show a skeleton.
- Mark the container `aria-busy="true"` with a label.
- Consumer provides: the shape of the content it stands in for.
