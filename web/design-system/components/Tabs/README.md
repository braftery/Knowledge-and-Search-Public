# Tabs

Switch between sibling views of one page. Underline style: the selected tab has `ink` text and a 3px `action` bar; the others have `ink-muted` text.

- A count sits in a neutral count chip when the tab holds a queue.
- Arrow keys move between tabs (WAI-ARIA tabs pattern). No animation on switch.
- The selected tab is in the URL, so refresh and share keep it.
- Use two to five tabs. Do not use tabs for steps in a sequence.
- Consumer provides: the tab labels, counts, and the selected value.
