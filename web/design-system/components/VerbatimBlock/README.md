# VerbatimBlock

Wording that Legal requires to be read exactly. The strongest treatment in the system, because a mistake here is a compliance risk.

- A 2px `ink` frame with an `ink` header strip in `ink-inverse`: lock icon and "Read to member, word for word". Text at 18px, 28px line height.
- Use only for units with the verbatim requirement. Ordinary approved wording is plain body text.
- Do not paraphrase, truncate or restyle the text inside. If it is long, let it wrap.
- Consumer provides: the approved text.
